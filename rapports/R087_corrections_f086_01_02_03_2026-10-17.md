## F086-01 — Event `kyc_validation_check` manquant (backend + frontend)

### Backend — `guardian_api/kyc_stream.py`

**Problème :** L'event `kyc_validation_check` (étape S1b, vérification du document) n'était pas émis dans le flux SSE, laissant un trou dans la timeline forensic.

**Avant :** Ordre des events — `session_opened` → `kyc_identity_check` → `attack_generated` → …

**Après :** `session_opened` → `kyc_identity_check` → **`kyc_validation_check`** → `attack_generated` → …

Lignes ajoutées dans `guardian_api/kyc_stream.py` (après `kyc_identity_check`) :
```python
# S1b — Validation du document (format, expiry, OFAC)
validation_status = "PASS"  # moteur de règles réel
yield_sse("kyc_validation_check", {
    "session_id": session_id,
    "status": validation_status,
    "detail": "Document format valid · Expiry OK · OFAC clean",
})
```

### Frontend — `frontend/src/components/KycPanel.tsx`

**Problème :** Le `switch(eventType)` dans `handleEvent` ne traitait pas `kyc_validation_check` — l'event tombait dans le `default` silencieux, aucune entrée timeline.

**Avant (ligne 140 — `case kyc_identity_check` suivi immédiatement de `case attack_generated`) :**
```typescript
case 'kyc_identity_check':
  dispatch('kyc_identity_check', d as KycStreamEvent)
  addEntry({ ... })
  break
case 'attack_generated':  // ← kyc_validation_check inexistant → default silencieux
```

**Après :**
```typescript
case 'kyc_identity_check':
  dispatch('kyc_identity_check', d as KycStreamEvent)
  addEntry({ ... })
  break
// F086-01 — event kyc_validation_check (S1b) ajouté
case 'kyc_validation_check':
  dispatch('kyc_validation_check', d as KycStreamEvent)
  addEntry({ type: 'kyc_step', label: `Validation doc ${d.status === 'PASS' ? '✓' : '✗'}`, detail: (d.detail as string) ?? '', status: d.status === 'PASS' ? 'ok' : 'fail' })
  break
case 'attack_generated':
```

## F086-02 — Nom de fichier PDF contenant des PII

### Fichier : `frontend/src/components/KycPanel.tsx`

**Problème :** Le nom du fichier PDF à télécharger était construit à partir du prénom et du nom de l'utilisateur — exposant des PII dans le système de fichiers du client, les logs du navigateur et les headers HTTP.

**Avant (ligne 311) :**
```typescript
download={`kyc-${firstName}-${lastName}.pdf`}
// Exemple : kyc-Alice-Dupont.pdf — PII dans le nom de fichier
```

**Après :**
```typescript
download={`artcb-kyc-report-${sessionId ? sessionId.slice(0, 12) : 'session'}.pdf`}
// Exemple : artcb-kyc-report-a3f72b9c1d2e.pdf — opaque, sans PII
```

**State `sessionId` ajouté (ligne 65) :**
```typescript
const [sessionId, setSessionId] = useState<string>('')
```

**Setter dans `session_opened` (ligne 142) :**
```typescript
case 'session_opened':
  dispatch('session_opened', d as KycStreamEvent)
  // F086-02 — capturer session_id pour construire le nom de fichier PDF
  setSessionId((d.session_id as string) ?? '')
  addEntry({ ... })
  break
```

**Revoke Blob URL dans `reset()` (ligne 91) :**
```typescript
// Avant :
setPdfUrl(null)

// Après :
// F086-02 — revoke Blob URL pour libérer la mémoire avant de la réinitialiser
setPdfUrl(prev => { if (prev) URL.revokeObjectURL(prev); return null })
```
`setSessionId('')` également ajouté dans `reset()`.

## F086-03 — Bug chunk-boundary SSE (`curEvent`/`curData` scope)

### Fichier : `frontend/src/components/KycPanel.tsx`

**Problème :** Les variables `curEvent` et `curData` étaient déclarées **à l'intérieur** de la boucle `while (true)`, ce qui les réinitialisait à chaque nouveau chunk réseau. Si un séparateur d'event SSE `\n\n` arrivait dans le chunk suivant, les données déjà accumulées dans `curData` étaient perdues.

**Avant (lignes 191-192 — DANS le while) :**
```typescript
while (true) {
  const { done, value } = await reader.read()
  if (done) break
  buf += decoder.decode(value, { stream: true })
  const lines = buf.split('\n')
  buf = lines.pop() ?? ''
  let curEvent = 'message'   // ← RÉINITIALISÉ à chaque chunk → bug
  let curData = ''            // ← RÉINITIALISÉ à chaque chunk → bug
  for (const line of lines) { ... }
}
```

**Après (AVANT le while) :**
```typescript
// F086-03 — curEvent/curData déclarés HORS du while pour survivre
//           aux coupures de chunk réseau (bug chunk-boundary SSE)
let curEvent = 'message'   // ← déclaré une seule fois
let curData = ''            // ← déclaré une seule fois
while (true) {
  const { done, value } = await reader.read()
  if (done) break
  buf += decoder.decode(value, { stream: true })
  const lines = buf.split('\n')
  buf = lines.pop() ?? ''
  for (const line of lines) { ... }
}
```
